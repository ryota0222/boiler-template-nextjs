# question

## What to do

- **Answer** the question.
- When the answer depends on a library, framework, SDK, API, CLI, or cloud service, consult official documentation first (context7 MCP, WebSearch, or WebFetch) and answer according to best practices and de facto standards.

## What NOT to do

- **MUST NOT** make any code changes whatsoever.
- A question is not a request for modifications. All code changes are strictly prohibited. No exceptions. Code changes are **forbidden**.
