# UI Blocks Rules

`@template/ui` (`packages/ui`) provides the Mantine theme (`createAppTheme`, `generateAccentColors`), `UiProvider`, the test helpers (`renderWithUi`, `TestLink`), and the blocks shared by every screen (`AppShellLayout`, `NavigationLinks`, `PageHeader`, `StatsGrid`, `DataTable`, `DetailCard`, `FormCard`, `ConfirmModal`, `EmptyCollection`, `ErrorBanner`, `StatusBadge`, `CollectionSkeleton`). `AppShellLayout` takes an `accountMenu` (`label`, `logoutLabel`, `logoutHref`) for the header's account menu, and the left navigation's content as `navigation` with its `navigationWidth` and `isNavigationFullHeight`. `packages/ui` is a copy of prototalk-enterprise's `packages/ui` without its CSV and authentication parts; it imports itself as `@template/ui/...` (never `@/`), may import nothing under `src/` (dependency-cruiser's `no-packages-depend-on-app`), and is not edited to fit one screen. When a later version is copied in, take the whole block, its story, and its test together.

A screen that needs one of the blocks uses the block instead of rebuilding it. A block takes every piece of data and every word of copy through its props, and takes Next.js's `Link` as `linkComponent`. `DataTable` takes its columns from `createDataTableColumnHelper` (`@template/ui/table/dataTableFeatures`) and expects an empty value as `undefined`, not `null`, because TanStack Table sorts only `undefined` last. A column opts into filtering, hiding, grouping, and the totals row through its `meta` (`DataTableColumnMeta`: `label`, `filterVariant`, `formatTotal`); a row-total column is an accessor that adds the row's values, with `aggregationFn: "sum"`. All of `DataTable`'s copy comes in one `labels` object (`DataTableLabels`); it may be rebuilt on every render. `columns` and `data` must keep their reference across renders — define `columns` at module level or in `useMemo`, and pass `data` straight from TanStack Query — because TanStack Table resets the page and the expanded groups whenever either reference changes.

Mantine components are used directly, with no wrapper components around them. `@tabler/icons-react` is the icon library. From a Server Component, write compound components in the `ComponentName` form (`TableTr`), because the dot notation (`Table.Tr`) does not work there. A Server Component must not pass `Link` as a Mantine component's `component` or a block's `linkComponent`: the prerender fails with "Functions cannot be passed directly to Client Components". Put the part that renders links in a `"use client"` component.
